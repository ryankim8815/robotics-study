# 03. ros2 param dump로 파라미터 관리하기

실행 중인 노드의 파라미터를 `ros2 param dump`로 YAML 파일에 저장하고, 파일을 고쳐서 다시 불러오는 실습입니다. [02. Docker에서 Python 노드 스크립트 실행하기](2026-1008-01-run-python-script.md)의 `lesson_13` 노드(`/lesson_13_cmd_vel_parameters`)를 대상으로 합니다. 이 노드는 `linear_speed`, `angular_speed` 파라미터를 쓰며, 기본값은 둘 다 1.0입니다.

- 환경: `osrf/ros:jazzy-desktop-full` (이 레포의 `desktop-full` 서비스)
- 검증: 2026-10-08, 실습 환경과 분리된 일회용 컨테이너에서 아래 명령을 모두 실행해 확인했습니다. 거북이 화면 대신 실제로 발행되는 속도 값으로 확인했습니다.

## 실습 흐름

```
실행 중인 노드 ──dump──▶ YAML 파일 ──(Mac에서 편집)──▶ load            : 실행 중에 적용
                                                   └▶ --params-file : 시작할 때 적용
```

설정 파일은 컨테이너의 `~/data/turtle_robot/params/`에 둡니다. Mac의 `data/turtle_robot/params/`와 같은 폴더라서 Mac 에디터로 바로 고칠 수 있고, git으로 변경 이력도 남길 수 있습니다.

## 0. 준비: 터미널 3개

Mac 터미널 탭 3개를 열고, 탭마다 컨테이너 셸에 들어갑니다.

```bash
cd ~/robotics/robotics-study && docker compose exec desktop-full bash
```

```
# 터미널 1
ros2 run turtlesim turtlesim_node

# 터미널 2
python3 ~/data/turtle_robot/lesson_13_cmd_vel_parameters.py

# 터미널 3: 아래 실습 명령을 여기서 입력
```

## 1. 현재 파라미터를 YAML로 보기

```
ros2 param dump /lesson_13_cmd_vel_parameters --timeout 5
```

```yaml
/lesson_13_cmd_vel_parameters:          # 노드 이름
  ros__parameters:                      # 고정 키워드
    angular_speed: 1.0
    linear_speed: 1.0
    start_type_description_service: true  # ROS가 자동으로 만드는 파라미터
    use_sim_time: false                   # ROS가 자동으로 만드는 파라미터
```

`--timeout 5`를 붙이는 이유가 있습니다. M1 환경에서는 노드가 막 떴을 때 기본 대기 시간(1초)으로 실행하면 `Node not found`가 나기 때문입니다.

## 2. 파일로 저장하기

Jazzy의 `dump`는 결과를 화면에만 출력하므로, 파일로 남기려면 `>`로 저장합니다.

```
# 저장할 폴더 만들기 (처음 한 번만. 폴더가 없으면 'No such file or directory' 오류가 납니다)
mkdir -p ~/data/turtle_robot/params

# 저장
ros2 param dump /lesson_13_cmd_vel_parameters --timeout 5 > ~/data/turtle_robot/params/lesson_13.yaml

# 내용 확인
cat ~/data/turtle_robot/params/lesson_13.yaml
```

⚠️ **`dump`가 실패해도 빈 파일(0바이트)이 생깁니다.** 꼭 `cat`으로 내용을 확인하세요. 빈 파일을 `load`하면 `TypeError: argument of type 'NoneType' is not iterable` 오류가 납니다.

## 3. 파일을 고쳐서 실행 중인 노드에 적용하기 (`load`)

Mac에서 `data/turtle_robot/params/lesson_13.yaml`을 열어 `linear_speed: 1.0`을 `2.0`으로 바꾸고 저장합니다. 그다음 적용합니다.

```
ros2 param load /lesson_13_cmd_vel_parameters ~/data/turtle_robot/params/lesson_13.yaml
ros2 param get /lesson_13_cmd_vel_parameters linear_speed
```

```
Set parameter angular_speed successful
Set parameter linear_speed successful
Set parameter use_sim_time successful
Set parameter start_type_description_service failed: Trying to set a read-only parameter: start_type_description_service.
```

마지막 `failed` 줄은 정상입니다. 노드가 시작된 뒤에는 바꿀 수 없는 읽기 전용 항목이라 나오는 메시지이고, 나머지 값은 적용됩니다. 거북이가 그리는 원이 커집니다.

## 4. 필요한 값만 남긴 설정 파일(프리셋) 만들기

`dump` 결과에서 내 파라미터만 남기면 파일이 읽기 쉬워지고, 위의 `read-only` 메시지도 나오지 않습니다. Mac에서 파일 두 개를 만드세요.

`data/turtle_robot/params/lesson_13_fast.yaml`

```yaml
/lesson_13_cmd_vel_parameters:
  ros__parameters:
    linear_speed: 2.5
    angular_speed: 0.8
```

`data/turtle_robot/params/lesson_13_slow.yaml`

```yaml
/lesson_13_cmd_vel_parameters:
  ros__parameters:
    linear_speed: 0.5
    angular_speed: 1.0
```

실행 중에 프리셋을 바꿔 가며 적용해 봅니다.

```
ros2 param load /lesson_13_cmd_vel_parameters ~/data/turtle_robot/params/lesson_13_fast.yaml
ros2 param load /lesson_13_cmd_vel_parameters ~/data/turtle_robot/params/lesson_13_slow.yaml
```

## 5. 시작할 때 불러오기 (`--params-file`)

터미널 2에서 Ctrl+C로 노드를 끈 뒤, 설정 파일을 지정해서 다시 실행합니다.

```
python3 ~/data/turtle_robot/lesson_13_cmd_vel_parameters.py --ros-args --params-file ~/data/turtle_robot/params/lesson_13_fast.yaml
```

터미널 3에서 `ros2 param get`으로 확인하면 `2.5`, `0.8`로 시작한 것을 볼 수 있습니다.

## 6. 우선순위: 뒤에 적은 것이 이깁니다

```
# 파일(2.5) 다음에 -p(4.0) → 결과 4.0
python3 ~/data/turtle_robot/lesson_13_cmd_vel_parameters.py --ros-args --params-file ~/data/turtle_robot/params/lesson_13_fast.yaml -p linear_speed:=4.0

# -p(4.0) 다음에 파일(2.5) → 결과 2.5
python3 ~/data/turtle_robot/lesson_13_cmd_vel_parameters.py --ros-args -p linear_speed:=4.0 --params-file ~/data/turtle_robot/params/lesson_13_fast.yaml
```

활용법은 이렇습니다. 파일을 기본 설정으로 두고, 그때그때 바꿀 값만 뒤에 `-p`로 덮어쓰면 됩니다.

## 7. 노드 이름과 상관없이 적용하기: 와일드카드 `/**`

`data/turtle_robot/params/any_node.yaml`

```yaml
/**:
  ros__parameters:
    linear_speed: 1.5
```

```
python3 ~/data/turtle_robot/lesson_13_cmd_vel_parameters.py --ros-args -r __node:=my_lesson --params-file ~/data/turtle_robot/params/any_node.yaml
ros2 param get /my_lesson linear_speed    # 1.5
```

노드 이름을 `my_lesson`으로 바꿔 실행해도 값이 적용됩니다.

## 8. 노드 2개의 설정을 한 파일로 관리하기

`data/turtle_robot/params/two_turtles.yaml`

```yaml
/slow_turtle:
  ros__parameters:
    linear_speed: 0.5
/fast_turtle:
  ros__parameters:
    linear_speed: 3.0
```

```
# turtle2 만들기
ros2 service call /spawn turtlesim/srv/Spawn "{x: 2.0, y: 2.0, theta: 0.0, name: 'turtle2'}"

# 터미널 2: 느린 노드 → turtle1을 움직임
python3 ~/data/turtle_robot/lesson_13_cmd_vel_parameters.py --ros-args -r __node:=slow_turtle --params-file ~/data/turtle_robot/params/two_turtles.yaml

# 터미널 4: 빠른 노드 → 토픽 이름을 바꿔서 turtle2를 움직임
python3 ~/data/turtle_robot/lesson_13_cmd_vel_parameters.py --ros-args -r __node:=fast_turtle -r /turtle1/cmd_vel:=/turtle2/cmd_vel --params-file ~/data/turtle_robot/params/two_turtles.yaml
```

- 같은 파일을 읽어도 각 노드는 자기 이름의 섹션만 적용합니다(0.5, 3.0).
- 터미널 4에서 토픽 이름을 바꾸지 않으면 두 노드가 같은 거북이에 서로 다른 속도를 번갈아 보내게 됩니다.

## 자주 하는 실수 (직접 재현해 본 결과)

| 실수 | 실행 중 `load` | 시작할 때 `--params-file` |
|---|---|---|
| 정수로 적기 (`linear_speed: 3`) | 거부됨: `Wrong parameter type, expected 'Type.DOUBLE' got 'Type.INTEGER'`. 기존 값 유지 | ❌ **노드가 시작하지 못하고 종료** (`InvalidParameterTypeException`) |
| 이름 오타 (`linear_sped`) | 거부됨: `Invalid access to undeclared parameter(s)` | ⚠️ **오류 없이 무시**되고 기본값 1.0으로 실행 |
| 노드 이름이 다른 파일 / 노드 여러 개가 든 파일 | ⚠️ **파일 안의 노드 이름을 무시하고 적용**됨. 여러 섹션이 있으면 마지막 값이 들어감 | 이름이 맞는 섹션만 적용 |

이 결과에서 나오는 규칙 세 가지입니다.

1. 코드에서 `1.0`처럼 소수로 선언한 값은 파일에도 **`3.0`처럼 소수점을 붙여** 적으세요.
2. 시작할 때의 이름 오타는 오류가 나지 않으니, 실행 후 **`ros2 param get`으로 실제 값을 확인**하세요.
3. 실행 중 `load`에는 **노드 1개짜리 파일**만 쓰세요(`dump` 결과가 원래 그렇습니다). 노드 여러 개짜리 파일은 시작할 때 `--params-file`로 쓰세요.

## 명령 요약

| 목적 | 명령 |
|---|---|
| 현재 값을 YAML로 보기 | `ros2 param dump <노드> --timeout 5` |
| 파일로 저장 | `ros2 param dump <노드> --timeout 5 > <파일>` |
| 실행 중 적용 | `ros2 param load <노드> <파일>` |
| 시작할 때 적용 | `--ros-args --params-file <파일>` |
| 값 하나만 덮어쓰기 | `--ros-args -p <이름>:=<값>` |

## 설정 파일을 git으로 관리하기

`data/turtle_robot/params/*.yaml`은 `.gitignore`에 걸리지 않으므로 커밋할 수 있습니다. 프리셋을 바꿀 때마다 커밋하면 설정이 어떻게 바뀌어 왔는지 기록이 남습니다.

```bash
cd ~/robotics/robotics-study && git add data/turtle_robot/params && git commit -m "lesson_13 파라미터 프리셋 추가"
```
