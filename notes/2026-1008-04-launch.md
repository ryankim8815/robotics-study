# 05. launch로 여러 노드를 한 번에 실행하기

지금까지는 터미널 3개가 필요했습니다. turtlesim용, `lesson_13`용, 명령 입력용입니다. launch 파일에 실행할 노드들을 적어 두면 **명령 하나로 모든 노드를 실행**하고, **Ctrl+C 한 번으로 모두 종료**할 수 있습니다. 터미널은 launch용과 명령 입력용, 2개면 됩니다.

[04. lesson_13 노드를 ROS 2 패키지로 만들기](2026-1008-03-ros2-package.md)에서 만든 `turtle_robot` 패키지에 launch 파일을 추가합니다.

- 환경: `osrf/ros:jazzy-desktop-full` (이 레포의 `desktop-full` 서비스)
- 검증: 2026-10-08, 실습 환경과 분리된 일회용 컨테이너에서 아래 launch 파일을 모두 빌드·실행해 확인했습니다.
- 참고: [ROS 2 Jazzy 공식 튜토리얼 – Launch](https://docs.ros.org/en/jazzy/Tutorials/Intermediate/Launch/Launch-Main.html)

## 터미널 구성 비교

| 이전 (터미널 3개) | launch 사용 (터미널 2개) |
|---|---|
| 터미널 1: `ros2 run turtlesim turtlesim_node` | 터미널 1: `ros2 launch turtle_robot lesson_13.launch.py` |
| 터미널 2: `ros2 run turtle_robot lesson_13 --ros-args -p ...` | |
| 터미널 3: 실습 명령 | 터미널 2: 실습 명령 |

## 0. 준비

⚠️ 먼저 기존 터미널에서 실행 중인 `turtlesim`과 `lesson_13`을 Ctrl+C로 모두 끄세요. 켜 둔 채 launch를 실행하면 같은 이름의 노드가 두 개씩 생깁니다. 그러면 `ros2 node list`에 `share an exact name` 경고가 나오고, `ros2 param get`이 어느 쪽 값을 읽을지 알 수 없게 됩니다.

컨테이너 셸에 들어갑니다.

```bash
cd ~/robotics/robotics-study && docker compose exec desktop-full bash
```

launch 파일과 설정 파일을 넣을 폴더를 만듭니다.

```
mkdir -p ~/ros2_ws/src/turtle_robot/launch ~/ros2_ws/src/turtle_robot/config
```

완성 후 패키지 구조입니다.

## 1. 첫 launch 파일: 노드 2개를 한 번에

Mac에서 `ws/src/turtle_robot/launch/lesson_13.launch.py`를 만듭니다.

```python
"""turtlesim과 lesson_13 노드를 한 번에 실행합니다."""

from launch import LaunchDescription
from launch.actions import Shutdown
from launch_ros.actions import Node


def generate_launch_description():
    return LaunchDescription([
        # 터미널 1에서 하던 일: ros2 run turtlesim turtlesim_node
        Node(
            package='turtlesim',
            executable='turtlesim_node',
            output='screen',
            on_exit=Shutdown(),  # 거북이 창을 닫으면 launch 전체를 종료
        ),
        # 터미널 2에서 하던 일: ros2 run turtle_robot lesson_13 --ros-args -p ...
        Node(
            package='turtle_robot',
            executable='lesson_13',
            output='screen',
            parameters=[{'linear_speed': 2.0, 'angular_speed': 0.5}],
        ),
    ])
```

| 코드 | 뜻 |
|---|---|
| `generate_launch_description()` | `ros2 launch`가 호출하는 함수. 실행할 것들의 목록을 돌려줍니다 |
| `Node(package=, executable=)` | `ros2 run <package> <executable>`과 같습니다 |
| `parameters=[{...}]` | `--ros-args -p 이름:=값`과 같습니다 |
| `output='screen'` | 노드의 로그를 launch 터미널에 출력합니다 |
| `on_exit=Shutdown()` | 이 노드가 끝나면 launch 전체를 종료합니다 |

### 설치 설정: `setup.py`, `package.xml`

launch 파일은 빌드할 때 설치(`install/`)되어야 `ros2 launch`가 찾을 수 있습니다. Mac에서 `ws/src/turtle_robot/setup.py`를 아래처럼 고칩니다. 바뀐 곳은 맨 위의 `import` 두 줄과 `data_files`의 마지막 두 줄입니다. `config/`는 3장에서 쓰지만 미리 넣어 둡니다.

```python
import os
from glob import glob

from setuptools import find_packages, setup

package_name = 'turtle_robot'

setup(
    name=package_name,
    version='0.0.0',
    packages=find_packages(exclude=['test']),
    data_files=[
        ('share/ament_index/resource_index/packages',
            ['resource/' + package_name]),
        ('share/' + package_name, ['package.xml']),
        (os.path.join('share', package_name, 'launch'), glob('launch/*.launch.py')),
        (os.path.join('share', package_name, 'config'), glob('config/*.yaml')),
    ],
    install_requires=['setuptools'],
    zip_safe=True,
    maintainer='root',
    maintainer_email='root@todo.todo',
    description='TODO: Package description',
    license='Apache-2.0',
    extras_require={
        'test': [
            'pytest',
        ],
    },
    entry_points={
        'console_scripts': [
            'lesson_13 = turtle_robot.lesson_13_cmd_vel_parameters:main',
        ],
    },
)
```

`ws/src/turtle_robot/package.xml`에는 실행할 때 필요한 패키지를 적습니다. `<depend>geometry_msgs</depend>` 아래에 두 줄을 추가하세요.

```xml
  <exec_depend>ros2launch</exec_depend>
  <exec_depend>turtlesim</exec_depend>
```

### 빌드하고 실행하기

```
cd ~/ros2_ws
colcon build --symlink-install --packages-select turtle_robot
source install/setup.bash

# 터미널 1: launch 실행
ros2 launch turtle_robot lesson_13.launch.py
```

로그 앞에 `[turtlesim_node-1]`, `[lesson_13-2]`처럼 어느 노드의 출력인지 표시됩니다. 터미널 2에서는 지금까지처럼 실습 명령을 쓰면 됩니다.

```
# 터미널 2
ros2 node list
ros2 param get /lesson_13_cmd_vel_parameters linear_speed    # 2.0
ros2 param set /lesson_13_cmd_vel_parameters linear_speed 2.5
```

### 종료하기

- **Ctrl+C:** 터미널 1에서 Ctrl+C를 누르면 두 노드가 함께 종료됩니다.
- **거북이 창 닫기:** `on_exit=Shutdown()` 덕분에 launch 전체가 종료됩니다.

⚠️ 종료할 때 `lesson_13` 쪽에 아래 메시지가 나올 수 있습니다.

```
[lesson_13-2] rclpy._rclpy_pybind11.RCLError: failed to initialize wait set: the given context is not valid ...
[ERROR] [lesson_13-2]: process has died [pid ..., exit code 1, ...]
```

- **무시해도 됩니다.** Python 노드가 종료 신호를 받는 순간과 내부 정리 순간이 겹쳐서 생기는 rclpy 종료 타이밍 문제입니다.
- **실습 코드 탓이 아닙니다.** ROS 공식 예제 노드(`demo_nodes_py`의 talker)도 이 환경(M1 에뮬레이션)에서 똑같이 나옵니다.
- **프로세스는 모두 정상적으로 종료됩니다.** 남는 프로세스가 없는 것을 확인했습니다.

## 2. launch 인자로 값 바꾸기

launch 파일을 고치지 않고 실행할 때 값을 바꿀 수 있게 합니다. `ws/src/turtle_robot/launch/lesson_13_args.launch.py`를 만듭니다.

```python
"""속도를 launch 인자로 받아서 실행합니다."""

from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument, Shutdown
from launch.substitutions import LaunchConfiguration
from launch_ros.actions import Node
from launch_ros.parameter_descriptions import ParameterValue


def generate_launch_description():
    return LaunchDescription([
        # launch 인자 선언: ros2 launch ... linear_speed:=3.0 처럼 바꿀 수 있음
        DeclareLaunchArgument('linear_speed', default_value='2.0', description='전진 속도'),
        DeclareLaunchArgument('angular_speed', default_value='0.5', description='회전 속도'),

        Node(
            package='turtlesim',
            executable='turtlesim_node',
            output='screen',
            on_exit=Shutdown(),
        ),
        Node(
            package='turtle_robot',
            executable='lesson_13',
            output='screen',
            parameters=[{
                # value_type=float: linear_speed:=3 처럼 정수로 넣어도 3.0(소수)으로 변환
                'linear_speed': ParameterValue(LaunchConfiguration('linear_speed'), value_type=float),
                'angular_speed': ParameterValue(LaunchConfiguration('angular_speed'), value_type=float),
            }],
        ),
    ])
```

새 launch 파일을 추가했으므로 **다시 빌드**합니다. 이미 있는 launch 파일을 고친 경우에는 빌드할 필요가 없습니다.

```
cd ~/ros2_ws && colcon build --symlink-install --packages-select turtle_robot && source install/setup.bash

# 받을 수 있는 인자 보기
ros2 launch turtle_robot lesson_13_args.launch.py --show-args

# 기본값(2.0, 0.5)으로 실행
ros2 launch turtle_robot lesson_13_args.launch.py

# 값 바꿔서 실행
ros2 launch turtle_robot lesson_13_args.launch.py linear_speed:=3.0 angular_speed:=1.0
```

`ParameterValue(..., value_type=float)`를 쓴 이유가 있습니다. 노드는 `linear_speed`를 소수(double)로 선언했기 때문에, 정수 `3`이 들어오면 [03장](2026-1008-02-param-dump.md)에서 본 것처럼 타입 오류로 시작하지 못합니다. `value_type=float`로 지정해 두면 `linear_speed:=3`으로 입력해도 3.0으로 바뀌어 들어가는 것을 확인했습니다.

## 3. 파라미터 파일(YAML)로 실행하기

[03장](2026-1008-02-param-dump.md)에서 만든 프리셋을 패키지의 `config/`에 넣어 두고 launch에서 불러옵니다. Mac에서 아래 두 파일을 만듭니다.

`ws/src/turtle_robot/config/lesson_13_fast.yaml`

```yaml
/lesson_13_cmd_vel_parameters:
  ros__parameters:
    linear_speed: 2.5
    angular_speed: 0.8
```

`ws/src/turtle_robot/config/lesson_13_slow.yaml`

```yaml
/lesson_13_cmd_vel_parameters:
  ros__parameters:
    linear_speed: 0.5
    angular_speed: 1.0
```

`ws/src/turtle_robot/launch/lesson_13_params.launch.py`

```python
"""파라미터 파일(YAML)을 지정해서 실행합니다."""

from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument, Shutdown
from launch.substitutions import LaunchConfiguration, PathJoinSubstitution
from launch_ros.actions import Node
from launch_ros.substitutions import FindPackageShare


def generate_launch_description():
    # 기본값: 설치된 패키지의 config/lesson_13_fast.yaml
    default_params = PathJoinSubstitution(
        [FindPackageShare('turtle_robot'), 'config', 'lesson_13_fast.yaml'])

    return LaunchDescription([
        DeclareLaunchArgument('params_file', default_value=default_params,
                              description='lesson_13 파라미터 파일 경로'),

        Node(
            package='turtlesim',
            executable='turtlesim_node',
            output='screen',
            on_exit=Shutdown(),
        ),
        Node(
            package='turtle_robot',
            executable='lesson_13',
            output='screen',
            parameters=[LaunchConfiguration('params_file')],
        ),
    ])
```

`FindPackageShare('turtle_robot')`는 설치된 패키지 폴더(`install/turtle_robot/share/turtle_robot`)를 찾아 줍니다. 그래서 launch 파일 안에 경로를 직접 적지 않아도 됩니다.

```
cd ~/ros2_ws && colcon build --symlink-install --packages-select turtle_robot && source install/setup.bash

# 기본: config/lesson_13_fast.yaml (2.5, 0.8)
ros2 launch turtle_robot lesson_13_params.launch.py

# 다른 파일 지정: lesson_13_slow.yaml (0.5, 1.0)
ros2 launch turtle_robot lesson_13_params.launch.py params_file:=$HOME/ros2_ws/src/turtle_robot/config/lesson_13_slow.yaml
```

`--symlink-install`로 빌드했기 때문에 `config/`의 YAML을 고치면 다시 빌드하지 않아도 다음 실행부터 반영됩니다.

## 4. 응용: 거북이 2마리를 한 번에

[03장 8절](2026-1008-02-param-dump.md)에서는 터미널 4개로 하던 일입니다. 거북이 추가(`spawn`), 노드 이름 바꾸기, 토픽 이름 바꾸기를 launch 파일 하나로 처리합니다.

`ws/src/turtle_robot/config/two_turtles.yaml`

```yaml
/slow_turtle:
  ros__parameters:
    linear_speed: 0.5
/fast_turtle:
  ros__parameters:
    linear_speed: 3.0
```

`ws/src/turtle_robot/launch/two_turtles.launch.py`

```python
"""거북이 2마리를 서로 다른 속도로 한 번에 움직입니다."""

from launch import LaunchDescription
from launch.actions import ExecuteProcess, Shutdown
from launch.substitutions import PathJoinSubstitution
from launch_ros.actions import Node
from launch_ros.substitutions import FindPackageShare


def generate_launch_description():
    params = PathJoinSubstitution(
        [FindPackageShare('turtle_robot'), 'config', 'two_turtles.yaml'])

    return LaunchDescription([
        Node(
            package='turtlesim',
            executable='turtlesim_node',
            output='screen',
            on_exit=Shutdown(),
        ),
        # turtle2 만들기 (서비스가 준비될 때까지 기다렸다가 호출됨)
        ExecuteProcess(
            cmd=['ros2', 'service', 'call', '/spawn', 'turtlesim/srv/Spawn',
                 "{x: 2.0, y: 2.0, theta: 0.0, name: 'turtle2'}"],
            output='screen',
        ),
        # 느린 노드 → turtle1
        Node(
            package='turtle_robot',
            executable='lesson_13',
            name='slow_turtle',
            output='screen',
            parameters=[params],
        ),
        # 빠른 노드 → 토픽 이름을 바꿔서 turtle2
        Node(
            package='turtle_robot',
            executable='lesson_13',
            name='fast_turtle',
            output='screen',
            parameters=[params],
            remappings=[('/turtle1/cmd_vel', '/turtle2/cmd_vel')],
        ),
    ])
```

| 코드 | 명령줄로 하던 것 |
|---|---|
| `ExecuteProcess(cmd=[...])` | 터미널에서 명령 실행 (`ros2 service call /spawn ...`) |
| `name='slow_turtle'` | `--ros-args -r __node:=slow_turtle` |
| `remappings=[(원래, 새것)]` | `--ros-args -r /turtle1/cmd_vel:=/turtle2/cmd_vel` |

```
cd ~/ros2_ws && colcon build --symlink-install --packages-select turtle_robot && source install/setup.bash
ros2 launch turtle_robot two_turtles.launch.py
```

```
# 터미널 2: 확인
ros2 node list                                   # /turtlesim, /slow_turtle, /fast_turtle
ros2 param get /slow_turtle linear_speed         # 0.5
ros2 param get /fast_turtle linear_speed         # 3.0
ros2 topic info /turtle2/cmd_vel -v              # 발행자: fast_turtle
```

turtle1은 작은 원, turtle2는 큰 원을 그립니다.

## 언제 다시 빌드해야 하나

| 한 일 | 다시 빌드 |
|---|---|
| 이미 있는 launch 파일, YAML, 노드 코드를 고침 | 필요 없음 (`--symlink-install`) |
| 새 launch 파일 / YAML / 노드 파일을 추가함 | 필요 |
| `setup.py`, `package.xml`을 고침 | 필요 |

빌드하지 않고 새 launch 파일을 실행하면 아래 오류가 납니다. `setup.py`의 `data_files`를 빠뜨렸을 때도 같은 오류가 납니다.

```
file 'xxx.launch.py' was not found in the share directory of package 'turtle_robot' ...
```

## 명령 요약

| 목적 | 명령 |
|---|---|
| launch 실행 | `ros2 launch turtle_robot <파일>.launch.py` |
| 받을 수 있는 인자 보기 | `ros2 launch turtle_robot <파일>.launch.py --show-args` |
| 인자 넘기기 | `ros2 launch turtle_robot <파일>.launch.py 이름:=값` |
| 빌드 + 반영 | `cd ~/ros2_ws && colcon build --symlink-install --packages-select turtle_robot && source install/setup.bash` |
| 전체 종료 | launch 터미널에서 Ctrl+C |
