# 04. lesson_13 노드를 ROS 2 패키지로 만들기

[02. Docker에서 Python 노드 스크립트 실행하기](2026-1008-01-run-python-script.md)에서는 `python3 파일경로`로 노드를 실행했습니다. 이번에는 `lesson_13` 노드를 `turtle_robot`이라는 ROS 2 패키지로 만들어 `ros2 run turtle_robot lesson_13`으로 실행합니다. 패키지로 만들어 두면 [05. launch](2026-1008-04-launch.md)에서 여러 노드를 한 번에 실행할 수 있습니다.

- 환경: `osrf/ros:jazzy-desktop-full` (이 레포의 `desktop-full` 서비스)
- 검증: 2026-10-08, 실습 환경과 분리된 일회용 컨테이너에서 아래 명령 블록을 그대로 붙여 넣어 실행해 확인했습니다.
- 참고: [ROS 2 Jazzy 공식 튜토리얼 – Creating a package](https://docs.ros.org/en/jazzy/Tutorials/Beginner-Client-Libraries/Creating-Your-First-ROS2-Package.html)

## 명령을 붙여 넣는 곳

각 명령 블록 위에 **Mac 터미널** 또는 **컨테이너 안**이라고 적어 두었습니다. 적힌 곳에 그대로 붙여 넣으면 됩니다.

- **Mac 터미널:** macOS의 터미널 앱입니다. **이 레포를 클론한 폴더(`compose.yaml`이 있는 레포 루트)로 이동한 뒤** 실행하세요. 문서에 나오는 Mac 쪽 경로는 모두 레포 루트 기준입니다.
- **컨테이너 안:** `docker compose exec desktop-full bash`로 들어간 셸입니다. 프롬프트가 `[desktop-full|jazzy|domain:0] ... #`처럼 보입니다.

같은 폴더가 Mac과 컨테이너에서 다른 경로로 보입니다.

| 용도 | 레포 기준 경로 (Mac 에디터로 열 때) | 컨테이너 경로 (명령에 쓰는 경로) |
|---|---|---|
| 워크스페이스 | `ws/` | `~/ros2_ws` |
| 패키지 소스 (git 커밋 대상) | `ws/src/turtle_robot/` | `~/ros2_ws/src/turtle_robot` |
| 빌드 결과 (`.gitignore`로 제외) | `ws/build/`, `ws/install/`, `ws/log/` | `~/ros2_ws/build`, `install`, `log` |
| 실습 원본 파일 | `data/turtle_robot/` | `~/data/turtle_robot` |

- **워크스페이스:** 패키지들을 모아 빌드하는 폴더입니다.
- **패키지:** 노드 코드와 실행 정보(`setup.py`, `package.xml`)를 묶은 단위입니다. 워크스페이스의 `src/` 아래에 만듭니다.

## 0. 준비

**Mac 터미널 (레포 루트):** 컨테이너 셸에 들어갑니다.

```bash
docker compose exec desktop-full bash
```

## 1. 패키지 만들기

**컨테이너 안:**

```
cd ~/ros2_ws/src && ros2 pkg create turtle_robot --build-type ament_python --license Apache-2.0 --dependencies rclpy geometry_msgs
```

| 옵션 | 뜻 |
|---|---|
| `turtle_robot` | 패키지 이름. 맨 앞에 적으세요. `--dependencies` 뒤에 적으면 의존성 이름으로 읽혀서 `the following arguments are required: package_name` 오류가 납니다 |
| `--build-type ament_python` | Python 패키지 |
| `--license Apache-2.0` | 라이선스. 빠뜨리면 `Unknown license` 경고가 나옵니다 |
| `--dependencies rclpy geometry_msgs` | 코드가 쓰는 패키지 (`package.xml`에 자동으로 들어감) |

만들어진 구조입니다(`~/ros2_ws/src/turtle_robot`).

```
turtle_robot/
├── package.xml          # 패키지 정보와 의존성
├── setup.py             # 설치 방법, 실행 파일 등록 (3장에서 수정)
├── setup.cfg
├── resource/turtle_robot
├── test/                # 코드 스타일 검사용 테스트
└── turtle_robot/        # 노드 코드를 넣는 곳 (패키지 이름과 같은 폴더)
    └── __init__.py
```

## 2. 노드 파일 넣기

**컨테이너 안:**

```
cp ~/data/turtle_robot/lesson_13_cmd_vel_parameters.py ~/ros2_ws/src/turtle_robot/turtle_robot/ && ls ~/ros2_ws/src/turtle_robot/turtle_robot/
```

`__init__.py`와 `lesson_13_cmd_vel_parameters.py`가 보이면 정상입니다.

이제부터는 패키지 안의 파일을 고치세요. 원래 `data/` 쪽 파일은 복사본이라 고쳐도 패키지에 반영되지 않습니다. Mac 에디터로 열 파일은 레포 기준으로 다음 경로입니다.

```
ws/src/turtle_robot/turtle_robot/lesson_13_cmd_vel_parameters.py
```

## 3. 실행 파일 등록하기 (`setup.py`)

`setup.py`의 `entry_points`에 아래 한 줄을 추가해야 합니다.

```python
            'lesson_13 = turtle_robot.lesson_13_cmd_vel_parameters:main',
```

- **`lesson_13`:** `ros2 run`에서 쓸 실행 이름입니다.
- **`turtle_robot.lesson_13_cmd_vel_parameters`:** `turtle_robot/` 폴더 안의 `lesson_13_cmd_vel_parameters.py` 파일입니다.
- **`main`:** 그 파일 안에서 실행할 함수입니다.

**컨테이너 안:** 아래 블록 전체를 붙여 넣으면 이 줄이 들어간 `setup.py`로 바뀝니다. 1장에서 만들어진 파일과는 `entry_points` 한 줄만 다릅니다.

```
cat > ~/ros2_ws/src/turtle_robot/setup.py <<'EOF'
from setuptools import find_packages, setup

package_name = 'turtle_robot'

setup(
    name=package_name,
    version='0.0.0',
    packages=find_packages(exclude=['test']),
    data_files=[
        ('share/ament_index/resource_index/packages',
            ['resource/' + package_name]),
        ('share/' + package_name, ['package.xml']),
    ],
    install_requires=['setuptools'],
    zip_safe=True,
    maintainer='root',
    maintainer_email='root@todo.todo',
    description='TODO: Package description',
    license='Apache-2.0',
    extras_require={
        'test': [
            'pytest',
        ],
    },
    entry_points={
        'console_scripts': [
            'lesson_13 = turtle_robot.lesson_13_cmd_vel_parameters:main',
        ],
    },
)
EOF
grep -n "lesson_13 =" ~/ros2_ws/src/turtle_robot/setup.py
```

마지막 줄의 결과로 `27:            'lesson_13 = ...'`이 보이면 정상입니다.

에디터로 직접 고치려면 Mac에서 아래 파일(레포 기준 경로)을 열어 `'console_scripts': [` 아래에 위의 한 줄을 넣으세요.

```
ws/src/turtle_robot/setup.py
```

## 4. 빌드하기

**컨테이너 안:**

```
cd ~/ros2_ws && colcon build --symlink-install --packages-select turtle_robot && source install/setup.bash
```

`Summary: 1 package finished`가 나오면 성공입니다.

- **`--symlink-install`:** 소스 파일을 복사하지 않고 링크로 설치합니다. Python 코드를 고친 뒤 다시 빌드하지 않아도 바로 반영됩니다.
- **`--packages-select turtle_robot`:** 이 패키지만 빌드합니다.
- **`source install/setup.bash`:** 빌드한 패키지를 지금 터미널에 알려 줍니다. **빌드할 때마다 실행**해야 해서 위 명령에 함께 넣었습니다.
- **`cb`:** 이 레포의 bashrc에는 빌드와 `source`를 한 번에 하는 별칭 `cb`가 있습니다. 워크스페이스 전체를 빌드합니다.
- **새로 여는 터미널:** bashrc가 `~/ros2_ws/install/setup.bash`를 자동으로 불러옵니다. 다만 **이미 열려 있던 터미널**은 직접 `source`해야 합니다. 명령은 아래와 같습니다.

```
source ~/ros2_ws/install/setup.bash
```

## 5. 실행하기

**컨테이너 안:** 등록된 실행 파일을 확인합니다. `turtle_robot lesson_13`이 보이면 정상입니다.

```
ros2 pkg executables turtle_robot
```

터미널이 하나 더 필요합니다. **Mac 터미널**에서 새 탭을 열고, 레포 루트로 이동한 뒤 컨테이너에 들어갑니다.

```bash
docker compose exec desktop-full bash
```

**컨테이너 안 (터미널 1):**

```
ros2 run turtlesim turtlesim_node
```

**컨테이너 안 (터미널 2):** 이전의 `python3 ~/data/...` 대신 실행합니다.

```
ros2 run turtle_robot lesson_13 --ros-args -p linear_speed:=2.0 -p angular_speed:=0.5
```

파라미터 사용법(`-p`, `--params-file`, `ros2 param set`)은 [03. ros2 param dump](2026-1008-02-param-dump.md)와 똑같이 쓸 수 있습니다. 멈출 때는 Ctrl+C를 누르세요.

## 6. 코드를 고치면? (`--symlink-install` 효과)

소스 파일을 고치고 저장한 뒤 **빌드 없이** 노드만 다시 실행하면 바뀐 코드가 적용됩니다. 기본값을 바꿔서 확인해 봅니다.

**컨테이너 안:** `linear_speed` 기본값을 1.0에서 1.5로 바꿉니다.

```
sed -i "s/declare_parameter('linear_speed', 1.0)/declare_parameter('linear_speed', 1.5)/" ~/ros2_ws/src/turtle_robot/turtle_robot/lesson_13_cmd_vel_parameters.py && grep -n "declare_parameter('linear_speed'" ~/ros2_ws/src/turtle_robot/turtle_robot/lesson_13_cmd_vel_parameters.py
```

**컨테이너 안 (터미널 2):** Ctrl+C로 노드를 끄고, 빌드하지 않은 채 `-p` 없이 다시 실행합니다.

```
ros2 run turtle_robot lesson_13
```

**컨테이너 안 (터미널 1):** turtlesim을 Ctrl+C로 끄고, 이 터미널에서 값을 확인합니다. `Double value is: 1.5`가 나오면 빌드 없이 반영된 것입니다.

```
ros2 param get /lesson_13_cmd_vel_parameters linear_speed
```

**컨테이너 안:** 확인이 끝나면 1.0으로 되돌립니다.

```
sed -i "s/declare_parameter('linear_speed', 1.5)/declare_parameter('linear_speed', 1.0)/" ~/ros2_ws/src/turtle_robot/turtle_robot/lesson_13_cmd_vel_parameters.py && grep -n "declare_parameter('linear_speed'" ~/ros2_ws/src/turtle_robot/turtle_robot/lesson_13_cmd_vel_parameters.py
```

다시 빌드해야 하는 경우는 다음과 같습니다.

- `setup.py`를 고쳤을 때 (실행 파일 추가, 설치 파일 추가)
- `package.xml`을 고쳤을 때
- 새 파일(새 노드, 새 launch 파일)을 추가했을 때

## 자주 나는 오류 (직접 재현해 본 결과)

| 오류 메시지 | 원인 | 해결 (컨테이너 안) |
|---|---|---|
| `Package 'turtle_robot' not found` | 빌드 후 이 터미널에서 `source`를 하지 않음 | `source ~/ros2_ws/install/setup.bash` |
| `No executable found` | `setup.py`의 `entry_points`에 등록하지 않았거나, 등록 후 다시 빌드하지 않음 | 3장을 다시 한 뒤 4장 빌드 명령 실행 |

## 참고

- **커밋:** 빌드하면 `ws/`에 `build/`, `install/`, `log/`가 생기지만 `.gitignore`로 제외되어 있습니다. 패키지 소스만 커밋하면 됩니다. **Mac 터미널 (레포 루트):**

  ```bash
  git add ws/src/turtle_robot && git status --short
  ```

- **`native` 프로파일로 바꿀 때:** 빌드 결과가 칩 종류(Intel/M1)마다 다르므로 지우고 다시 빌드해야 합니다(README 참고). **Mac 터미널 (레포 루트):**

  ```bash
  rm -rf ws/build ws/install ws/log
  ```
